# Hearth & Wheat

Welcome to the **Hearth & Wheat** bakery website repository. This is a premium, beautifully designed responsive website for an artisanal bakery that specializes in slow-fermentation sourdough and hand-built pastries baked in a wood-fired hearth.

## Features

- **Modern & Elegant Design**: A cohesive aesthetic featuring premium typography, beautiful photography, and a warm, inviting color palette (`cream`, `walnut`, `crust`, `wheat`).
- **Responsive Layout**: fully responsive on mobile and desktop, utilizing CSS Grid and Flexbox.
- **Interactive UI**: Micro-interactions, hover states, a custom testimonial slider, overlapping editorial cards, and smooth CSS transitions.
- **Leaflet Maps Integration**: Interactive map on the Contact page for easy navigation.
- **No Dependencies**: Built entirely with pure HTML, vanilla CSS, and vanilla JavaScript (no heavy frameworks).

## Pages

1. **Home (`index.html`)**: Features the hero banner, signature collections, highlighted products, and a customer testimonial slider.
2. **About Us (`about.html`)**: An "Editorial Magazine" layout telling the story of the bakery, introducing the Head Baker, detailing the baking principles, and presenting a typographic timeline.
3. **Product / Collections (`product.html`)**: A beautiful overlapping product catalog with filter tabs (All, Bread, Pastry) and interactive add-to-cart buttons.
4. **Contact (`contact.html`)**: A split-layout page with an overlapping white panel, clean input fields, business hours, and an integrated Leaflet map.

## Setup

Since this is a static website, no build process or server is required. 
Simply open `index.html` in your favorite web browser to view the site, or use a tool like Live Server in VS Code for hot-reloading during development.

## Technologies Used
- HTML5
- CSS3 (Custom Properties / Variables, Grid, Flexbox)
- JavaScript (Vanilla)
- Leaflet.js (for maps)
- Google Fonts (Fraunces, Work Sans, Space Mono)
